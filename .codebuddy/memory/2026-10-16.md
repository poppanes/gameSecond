## 登录形态决策（对齐完成）
- 结论：多小程序平台上线用「游客模式默认可玩 + 平台原生静默登录（wx.login 等）+ 昵称头像按需授权（getUserProfile）」，**不做传统登录页**（账号密码/手机号流失率高、手机号需企业认证）。
- 关键架构：登录逻辑与登录 UI 分离——游戏逻辑只依赖 User 对象，平台差异封装在适配器。Canvas 游戏上微信应走「小游戏」类目（adapter 生态 + 虚拟支付），建议配合微信云开发做 code2session（免自建服务器）。
