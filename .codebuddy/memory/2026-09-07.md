# 2026-09-07

## 角色速度平衡调整
用户反馈：角色速度太快导致游戏不平衡。

### 调整（按推荐值）
- **`player.js:24` `moveSpeed`**：`0.55` → `0.40`（~220ms/格）
- **`input.js:37` `TURN_BOOST`**：`3` → `2`（减少转向时的"窜"感）

### 速度参数速查（调平衡时参考）
| 对象 | 位置 | 值（调整后） |
|---|---|---|
| 角色 | `player.js:24` `moveSpeed` | **0.40** |
| 转向加速 | `input.js:37` `TURN_BOOST` | **2** |
| 幽灵/猫头鹰 | `enemy.js:7` `ENEMY_MOVE_SPEED` | 0.25 |
| 雪人狂暴 | `enemy.js:16` `SNOWMAN_RAGE_SPEED` | 0.45 |
| 章鱼 | Octopus 构造 `* 1.6` | 0.40 |
| 蜘蛛 | Spider 构造 `* 0.5` | 0.125 |
| 危险期怪物提速 | `enemy.js:27` `TIME_DANGER_SPEED_MULT` | 1.5（剩余<50s） |
| 危险期阈值 | `enemy.js:26` `TIME_DANGER_THRESHOLD` | 50000ms |

### 历史值
- 原始（优化前）：0.35（~250ms/格）
- 流畅化一版：0.45
- 流畅化二版：0.55（用户反馈太快）
- 当前：0.40（2026-09-07 平衡值）

### 备注
- 若日后仍觉得快：继续降到 0.35（回到原始）
- 若觉得慢/想增强压迫感：优先提怪物速度（`ENEMY_MOVE_SPEED`）或降低 `TIME_DANGER_THRESHOLD` 的触发时机

## 测试地图新增道具放置（2026-09-17）
用户需求：测试地图要能放置道具。

### 实现（沿用「按键选工具 + 鼠标点击放置」交互）
- **`game.js`**：
  - `TEST_TOOL_NAMES` 增加 9 种道具中文名（cherry/apple/peach/watermelon/icecream/time/hammer/heart/boom）
  - 新增 `TEST_ITEM_TYPES` 数组（道具循环顺序）
  - `testKeyDown` 加 `KeyI` → `_cycleTestItem()`（循环切换道具类型）
  - `_applyTestTool` 加道具 case：`items.push(new Item(tool, col, row))`
  - `drawTestHelp` 底部说明加第三行「道具: [I]循环切换(...)」
- **`input.js`**：testKeys 列表加 `KeyI`

### 交互
- 按 `[I]` 循环切换道具类型（樱桃→苹果→桃子→西瓜→雪糕→沙漏→铁锤→爱心→炸弹→循环）
- 鼠标点击格子 → 在该格放置当前道具
- 道具数据在 `item.js` 的 `ITEM_TYPES`（src/score/category），`new Item(type,col,row)` 直接 push 到 `items` 数组
